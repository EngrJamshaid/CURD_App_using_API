# CRUD Application using API

This is a simple CRUD (Create, Read, Update, Delete) application built using PHP and MySQL with API endpoints.  
The project demonstrates how to perform basic database operations using fetch API on the frontend and PHP backend for handling requests.

## Features

- User-friendly interface to add, view, edit, and delete records
- PHP backend API to handle CRUD operations
- MySQL database to store user data
- JavaScript Fetch API for asynchronous requests
- Simple validation on the frontend

## Technologies Used

- PHP
- MySQL
- JavaScript (Fetch API)
- HTML/CSS
- Postman
